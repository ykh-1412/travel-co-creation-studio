# 旅行方案档案

这里保存已经做过的旅行方案，目的是保留当时的行程、预算思路、Excel、提示词和页面素材，方便以后查看或重新切换。

## 当前方案

- 韩国济州岛：当前正在运行的网站方案，代码位于仓库根目录。
- 当前 Excel：`outputs/019fa660-42f1-74a1-ab98-31c99abb6300/韩国济州岛旅行共创.xlsx`
- 当前数据：`data/store.json`

## 历史方案

- [`yangzhou/`](./yangzhou/)：扬州 6 人周末旅行完整归档。

每个历史方案可包含：

- `README.md`：方案背景和归档说明。
- `PROMPTS.md`：人数、天数、住宿、餐饮、活动等关键要求。
- `state.json`：恢复网站时使用的结构化数据。
- `.xlsx`：方便直接查看的完整旅行 Excel。
- `assets/`：当时使用的分享图和品牌图片。

## 以后如何切换

需要重新启用历史方案时，先阅读对应目录的 `README.md` 和 `PROMPTS.md`，再把 `state.json`、Excel 和品牌图恢复到当前网站，修改项目名称和运行配置，最后重新执行测试并发布。

归档中不保存 `.env`、共享密码或 AI API Key。
